## SLIDE 12: SQL INJECTION ATTACK

Definition:

SQL Injection is a security vulnerability that happens when an application improperly handles user input and allows malicious SQL commands to affect database queries.

Example of a vulnerable query:

SELECT * FROM users
WHERE username = 'user_input'
AND password = 'user_password';

Possible effects:

- Unauthorized login.
- Access to confidential information.
- Modification of database records.
- Deletion of important data.

Prevention:

- Use prepared statements.
- Validate user input.
- Avoid directly combining user input with SQL commands.
- Apply least-privilege permissions.

IMPORTANT:
Display the SQL code in a clearly formatted code block. Explain that this is an example of a vulnerable query structure, not a recommended login implementation.
