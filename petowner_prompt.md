# MASTER PROMPT: COMPLETE VETLINK PET OWNER MOBILE APPLICATION UI/UX DESIGN

## PROJECT TITLE
VetLink: A Mobile-Based Veterinary Clinic Locator, Appointment Booking, and Pet Health Record Management System

## 1. PROJECT OBJECTIVE

Act as a senior UI/UX designer, mobile application designer, and professional Figma design engineer.

Your task is to design a COMPLETE, HIGH-FIDELITY MOBILE APPLICATION for the PET OWNER interface of VetLink.

Create the entire application, beginning with the Splash Screen, Onboarding Screens, Authentication, Home Dashboard, Veterinary Clinic Locator, Appointment Booking, Pet Profile Management, Pet Health Records, Appointment Management, AI-Assisted Inquiry, and all Profile and Settings pages.

IMPORTANT: This is a complete application design task. Do not generate only a sample, concept, landing page, or a limited selection of screens.

Every screen specified in this prompt must have its own properly designed mobile frame.

The final result must look like a professionally developed veterinary healthcare mobile application that could realistically be implemented by a development team.

- Use consistent horizontal margins.
- Use approximately 16–20 px screen padding.
- Use 12–16 px card corner radii.
- Use 8–12 px button corner radii.
- Use subtle shadows.
- Use light and consistent borders.
- Maintain adequate whitespace.
- Respect mobile safe areas.
